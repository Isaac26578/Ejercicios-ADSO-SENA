Ejercicios y Prácticas - Análisis y Desarrollo de Software (SENA)
Este repositorio recopila los ejercicios prácticos, talleres y retos de programación desarrollados durante mi proceso de formación como tecnólogo en Análisis y Desarrollo de Software (ADSO) en el SENA.

El objetivo de este espacio es documentar mi evolución técnica, aplicar buenas prácticas de desarrollo y consolidar los fundamentos de la ingeniería de software.

Temas y Competencias Abordadas
A lo largo de los distintos módulos, los ejercicios se centran en:

Lógica de Programación: Estructuras de control, ciclos, arreglos, matrices y resolución de problemas algorítmicos.

Programación Orientada a Objetos (POO): Clases, objetos, herencia, polimorfismo, encapsulamiento e interfaces.

Bases de Datos: Modelado Entidad-Relación (MER), normalización y consultas SQL (DDL, DML).

Desarrollo Web: Maquetación, estilos y dinamismo del lado del cliente y servidor.

Control de Versiones: Gestión de código fuente mediante Git y GitHub.
